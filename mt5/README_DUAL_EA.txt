SignalX Dual-Symbol EA

One EA instance can execute both XAUUSDm and EURUSDm orders.
The EA no longer requires the chart symbol to match the queued order symbol.

Defaults:
  XAUTradeSymbol = XAUUSDm
  EURTradeSymbol = EURUSDm

Attach ONE SignalX_Dual_Symbol_EA.mq5 to any MT5 chart.
Keep Algo Trading ON and allow WebRequest to the Railway ApiBase URL.

This package changes only the MT5 EA routing logic. It does not modify the web UI.
